About FeatherOS
Eiderdown.

A lightweight classic-desktop Linux OS based on Ubuntu 22.04 LTS — GNOME Flashback + Metacity + LightDM, custom Plymouth splash, zero snaps, Firefox from Mozilla’s apt repository, and the full Ubuntu 22.04 application set.

  • GNOME Flashback session with Metacity (“Feather” Yaru-style window theme)
  • LightDM with a FeatherOS greeter background
  • Custom “feather” Plymouth boot splash
  • Eiderdown wallpaper + FeatherOS branding end to end
  • No snapd — apt and .deb only
  • Live session autologins as feather; installed systems get a normal login
↗

The amd64 image boots on BIOS and UEFI (including Secure Boot) and includes the classic Ubiquity installer—“Install FeatherOS” appears on the live desktop.
