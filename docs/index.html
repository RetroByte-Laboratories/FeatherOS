How to assemble the ISO

Place all three downloads in one folder. Verify the parts, then join them:

sha256sum -c SHA256SUMS
cat FeatherOS-6.1-eiderdown-desktop-amd64.iso.part-* > FeatherOS-6.1-eiderdown-desktop-amd64.iso

On Windows Command Prompt, use copy /b part-00+part-01 FeatherOS-6.1-eiderdown-desktop-amd64.iso.

GOOD TO KNOW

Frequently asked
questions.

Will FeatherOS start the graphical desktop automatically?

Yes. The current Eiderdown build defaults to the graphical systemd target and explicitly enables LightDM. The live session is configured to log in to the FeatherOS Flashback desktop.

Why are there two ISO downloads?

The ISO is larger than GitHub's per-file release asset limit. Download both numbered parts and the SHA256SUMS file, verify the chunks, then join them using the instructions above.

How do I make a bootable USB?

After assembling the ISO, use a trusted USB imaging tool such as balenaEtcher, Rufus or Ventoy. Double-check the selected USB drive; writing an image erases it.

What computers are supported?

This release is for 64-bit amd64 PCs and supports BIOS and UEFI boot. Try the live session first to check your hardware before installing.

Is FeatherOS an official Ubuntu edition?

No. FeatherOS is an independent community project by RetroByte Laboratories. It is based on Ubuntu and is not affiliated with or endorsed by Canonical.
