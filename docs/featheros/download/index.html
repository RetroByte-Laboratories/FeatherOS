Verify and assemble the ISO

Put the two parts and SHA256SUMS in the same folder. On Linux or macOS:

sha256sum -c SHA256SUMS
cat FeatherOS-6.1-eiderdown-desktop-amd64.iso.part-* > FeatherOS-6.1-eiderdown-desktop-amd64.iso

On Windows Command Prompt:

copy /b FeatherOS-6.1-eiderdown-desktop-amd64.iso.part-00+FeatherOS-6.1-eiderdown-desktop-amd64.iso.part-01 FeatherOS-6.1-eiderdown-desktop-amd64.iso
